# Construction Materials ERP (ระบบ ERP สำหรับร้านจำหน่ายวัสดุก่อสร้าง)

ระบบ ERP บริหารจัดการร้านค้าและคลังวัสดุก่อสร้างครบวงจร พัฒนาด้วย **Next.js (App Router + TypeScript) + SQLite** พร้อมการออกแบบอินเทอร์เฟซตามแนวทาง **Airbnb Design System**

## ✨ คุณสมบัติหลัก (Key Features)

1. **ภาพรวมธุรกิจ (Executive Dashboard)**: สรุปยอดขายวันนี้/เดือนนี้, กำไรขั้นต้น (Gross Profit), สต็อกต่ำกว่าจุดสั่งซื้อ, ยอดลูกหนี้คงค้าง (AR) และเจ้าหนี้ (AP)
2. **จุดขายหน้าร้าน (POS System)**:
   - ค้นหาสินค้าหรือสแกนบาร์โค้ด
   - ระบบราคา 4 ระดับ (ราคาปลีก, ราคาช่าง, ราคาผู้ผู้รับเหมา, ราคาโครงการ)
   - สลับหน่วยนับขาย (Multi-UOM) เช่น ถุง, ตัน, เส้น, มัด พร้อมคำนวณราคาอัตโนมัติ
   - พักบิล (Hold) และเรียกคืนบิล (Recall)
   - ชำระเงินสด (คำนวณเงินทอน), เงินโอน PromptPay, บัตรเครดิต, และการขายเชื่อ (Credit Sale)
3. **การพิมพ์เอกสาร (Printable Receipts & Tax Invoices)**:
   - พิมพ์ใบเสร็จรับเงินอย่างย่อขนาด 80mm สำหรับเครื่องพิมพ์สลิปความร้อน
   - พิมพ์ใบส่งของ / ใบกำกับภาษีเต็มรูปขนาด A4
4. **จัดการสินค้าและหลายหน่วยนับ (Products & Multi-UOM)**:
   - บันทึก SKU, บาร์โค้ดหลายรายการ, ต้นทุนสินค้า, จุดสั่งซื้อ (Reorder Point)
   - ป้องกันการลบข้อมูลประวัติย้อนหลังด้วย Soft Delete
5. **ใบเสนอราคา (Quotations)**: สร้างใบเสนอราคา ติดตามสถานะ และกดแปลงเป็นบิลขายตัดสต็อกได้ใน 1 คลิก
6. **จัดซื้อและตรวจรับสินค้า (Procurement & GRN)**: ออก PO ตรวจรับสินค้าเข้าคลัง บันทึก Stock Card ขาเข้า (IN) และคำนวณต้นทุนถัวเฉลี่ยเคลื่อนที่ (Moving Average Cost)
7. **คลังสินค้าและสต็อกการ์ด (Warehouse & Stock Cards)**: ยอดคงเหลือแยกตามคลัง, บันทึกประวัติการเคลื่อนไหว (Stock Card), โอนย้ายสินค้าระหว่างคลัง, และปรับปรุงยอดสต็อก
8. **จัดส่งสินค้า (Delivery Management)**: มอบหมายคนขับและทะเบียนรถ ติดตามสถานะจัดส่ง (รอจัดของ, กำลังส่ง, ส่งสำเร็จ)
9. **ลูกหนี้และการรับชำระ (Accounts Receivable - AR)**: รายงานอายุหนี้ (AR Aging: 0-30 วัน, 31-60 วัน, >60 วัน) และบันทึกตัดรับชำระหนี้
10. **เจ้าหนี้และการจ่ายชำระ (Accounts Payable - AP)**: รายการผู้จำหน่าย ใบสั่งซื้อค้างจ่าย และออกใบสำคัญจ่าย
11. **การเงินและกะขาย (Finance & Shift)**: เปิด/ปิดกะขายพร้อมกระทบยอดเงินสดนับจริงในลิ้นชัก (Reconciliation) และบันทึกค่าใช้จ่ายรายวัน (Petty Cash)
12. **รายงาน (Reports)**: รายงานยอดขาย, กำไรขั้นต้น (Gross Margin %), มูลค่าสต็อกตามราคาทุน, และรายงานอายุหนี้

## 🚀 เริ่มต้นใช้งาน (Getting Started)

ติดตั้ง dependencies:
```bash
npm install
```

รัน Development Server:
```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

## 🛠️ โครงสร้างฐานข้อมูล (Database)
- ฐานข้อมูล **SQLite** จัดเก็บในไฟล์ `data/construction.db` โดยรันในโหมด WAL (Write-Ahead Logging)
- ระบบมี Mockup Data ตัวอย่างวัสดุก่อสร้างไทย (ปูน SCG, เหล็ก TATA, ท่อตราช้าง, ยาแนวจระเข้, สี TOA) ให้พร้อมทดสอบ
- สามารถกดปุ่ม **"รีเซ็ตและโหลดข้อมูลจำลองใหม่"** ได้ในหน้า **ตั้งค่าระบบ (Settings)** ตลอดเวลา
